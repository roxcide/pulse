# PULSE — фитнес-трекер

Адаптивное SPA на React 19, Vite и Lucide React. Интерфейс на русском языке, тёмная тема с лаймовыми акцентами.

## Запуск

Node.js `24.19.0`, pnpm `11.25.0`. Версии зависимостей зафиксированы в `pnpm-lock.yaml`.

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm run dev
```

Сборка: `pnpm run build`. Просмотр сборки: `pnpm run preview`.
Проверка оформления кода: `pnpm run format:check`.

## Публикация

Проект подготовлен для **GitHub → Cloudflare Pages**. В репозиторий загружаются исходники с `package.json` в корне; Cloudflare собирает их командой `pnpm run build` и публикует папку `dist`.

Полная инструкция, параметры Cloudflare и вариант загрузки готового ZIP — в [DEPLOY.md](DEPLOY.md).

В `.github/workflows/build.yml` настроена автоматическая проверка сборки для коммитов в `main` и pull request. `node_modules`, `dist`, локальные переменные окружения и архивы из `release` исключены из Git.

## Возможности

- Главная: тренировка дня, недельная цель, статистика, расписание и программы.
- Тренировка: вес и повторения для каждого подхода, дополнительные подходы и упражнения, автоматический таймер отдыха с паузой, сохранение результатов.
- Библиотека: поиск, фильтры мышц и оборудования, свои упражнения.
- Календарь: месячный и недельный режимы, история и разовые планы.
- Сплит: редактирование каждого дня недели.
- Профиль: имя, недельная цель, длительность отдыха, очистка демонстрационной истории.

Данные и активная тренировка сохраняются в localStorage. Начальные записи помечены как демонстрационные. Сервер, авторизация и синхронизация между устройствами не подключены. Таймеры вычисляются по абсолютному времени, поэтому выдерживают перезагрузку страницы и фоновый режим.

## Структура

- `src/App.jsx` — экраны и сценарии приложения.
- `src/components.jsx` — календарь, недельное расписание, модальные окна.
- `src/data.js` — каталог, программы и функции дат.
- `src/hooks.js` — сохранение состояния в браузере.
- `src/styles.css` — оформление, адаптивные состояния, reduced-motion.
- `public/images` — локальные фотографии Unsplash.
